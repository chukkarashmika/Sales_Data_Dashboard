# Sales Data Dashboard

## Project Overview

This project analyzes sales data to understand business performance using Python and data visualization.

## Objectives

* Analyze total sales, profit, quantity, and orders.
* Identify monthly sales trends.
* Compare sales across different regions.
* Analyze sales and profit by category.
* Identify the top-performing products.
* Generate useful business insights from sales data.

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

## Key Results

* **Total Sales:** $2,297,200.86
* **Total Profit:** $286,397.02
* **Total Orders:** 5,009
* **Total Quantity Sold:** 37,873
* **Highest Sales Region:** West
* **Highest Sales Category:** Technology
* **Highest Profit Category:** Technology
* **Top Product by Sales:** Canon imageCLASS 2200 Advanced Copier

## Visualizations

The project includes visualizations for:

* Monthly Sales Trend
* Sales by Region
* Sales by Category
* Profit by Category
* Top 10 Products by Sales

## Conclusion

The analysis demonstrates how Python-based data analysis and visualization can transform raw sales data into meaningful business insights and support data-driven decision-making.
